Sutton CC Tournament Manager - iPad Install

1. Unzip this folder.
2. Upload the folder to Netlify Drop or GitHub Pages, OR open index.html directly from Files.
3. On the iPad, open the app link in Safari.
4. Tap Share.
5. Tap Add to Home Screen.
6. Open it once before tournament day and test New Tournament.

At the ground it works offline after it has been opened once.
